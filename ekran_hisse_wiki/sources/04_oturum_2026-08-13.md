# Oturum 2026-08-13 — Resize özelliği + Tweet alarm teşhisi

Bu snapshot, 2026-08-13 geliştirme oturumunun ham bulgularını dondurur. İki iş:

## 1. Yatay/Dikey boyutlandırma + kalıcılık (yeni özellik)

Kullanıcı isteği: "tüm ekranları yatay ve dikey uzatabileyim. uzatılmış halini
kaydetsin ve hep öyle açsın." Seçilen yöntem: kenar/köşeden sürükle.

Pencere sağ-alta yaslı frameless HUD → boyutlandırılabilir kenarlar SOL (genişlik),
ÜST (yükseklik, yukarı büyür), SOL-ÜST köşe (ikisi). Sağ kenar sekme şeridi + alt
kenar ekran-yaslaması sabit.

Uygulanan (`overlay.py`):
- Sabitler: `PANEL_W_MIN=220`, `PANEL_W_MAX=900`, `WIN_H_MIN=200`, `RESIZE_MARGIN=6`.
- `GEOM_FILE = ~/.ekranhisse/ui_geom.json`; `load_geom()`/`save_geom()` — font-ölçeği
  (`ui_scale.json`) kalıcılık desenini birebir yansıtır. Kayıt yoksa panel_w=PANEL_W,
  win_h=ekran//2. Release'te kaydeder (disk yıpratma yok).
- Sabit `PANEL_W`/`ekran//2` yerine çalışma zamanı `self._panel_w`/`self._win_h`;
  `_toggle` animasyonu, `_reposition_to_screen`, `_SheetDialog._place` bu değeri kullanır.
- OverlayWindow'a `mousePressEvent`/`mouseMoveEvent`/`mouseReleaseEvent`/`_hit_zone`;
  imleç geri bildirimi (SizeHor/SizeVer/SizeFDiag). Resize sırasında "dışarı tık =
  kapat" 4 yolun hepsinde `_resize_edge` guard'ıyla devre dışı.
- 211 test geçti (10 yeni: roundtrip, clamp, defaults, runtime genişlik, hit-zone,
  anchor-sabitleme, kapanmama, sadece-geom-dosyası). Kullanıcı verisi (stocks.json,
  notlar) korundu — yalnız `ui_geom.json` yazılıyor.

Not: Font büyüt/küçült (A−/A+) özelliği önceki oturumda eklenmişti (`ui_scale.json`,
`_FONT_SCALE`, `_sf()`, A−/A+ butonları başlık satırında, `_rebuild_all_pages`).

## 2. Tweet alarm teşhisi — X API 402 "credits depleted"

Kullanıcı: "tweet alarm mekanızması çalışıyor olabilir mi". Alarm = 𝕏 sekmesindeki
kırmızı rozet (`_tw_unread` sayacı) + yeni tweet vurgusu (`_tw_hl`). Sesli/sistem
bildirimi YOK, sadece görsel.

Canlı API probe (`api.twitter.com/2/tweets/search/recent`, geçerli bearer token,
114 karakter):
```
HTTP 402
{"detail":"credits depleted","status":402,"title":"Payment Required",
 "type":"https://api.x.com/2/problems/credits-depleted"}
```

Kök neden: KOD DEĞİL, HESAP/PLAN. X API v2 `search/recent` artık ücretli; hesabın
kredisi tükenmiş. Zincir: `_twitter_poll` (60 sn) → `_request` 402 → poll boş →
`_tw_unread` dolmaz → rozet hiç görünmez.

İkincil gözlem: `_twitter_poll_error` hatayı yalnız 𝕏 sekmesi AÇIKKEN status'a yazar;
kapalıyken sessizce loglar → kullanıcı nedeni göremiyor.

Config gerçeği: `config.TWITTER_QUERY` artık `_twitter_query()` tarafından OKUNUYOR
(override doluysa aynen, boşsa `twitter_query(self._tw_symbols)`). Yani known_issues'daki
"TWITTER_QUERY dead config" maddesi artık geçersiz.

Çözüm (kod dışı): X Developer Portal'da plan/kredi yenile, veya kredili bir bearer
token ile `security add-generic-password -U -s ekranhisse -a TWITTER_BEARER_TOKEN
-w '<token>'` + restart.
